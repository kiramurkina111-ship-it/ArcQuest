# ArcQuest

ArcQuest — небольшая обучающая браузерная игра про Arc, stablecoin-платежи и onchain-бейджи за прохождение уровней.

Смотри [DEPLOY.ru.md](./DEPLOY.ru.md): там инструкция по деплою контракта в Arc Testnet, настройке фронтенда, NFT minting и публикации статического сайта.

## Текущая версия

Миссия 01, **Pay the Grid**, уже играбельна без кошелька. Кликайте по следующему узлу на карте, чтобы провести USDC-платеж до мерчанта. Стабильные маршруты дают предсказуемые комиссии, нестабильные могут внезапно подорожать.

ArcQuest теперь открывается на вдохновленном Arc бело-синем экране выбора миссий и использует локальные официальные SVG-логотипы Arc с сайта Arc. Ссылки на ресурсы вынесены в нижний блок с дисклеймером о фанатском статусе игры и кредитом создателя: Built by Kira, [X: Kiiiiira777](https://x.com/Kiiiiira777), Discord: `kiira7094`. Такой же блок ресурсов и дисклеймера теперь показывается под игровыми уровнями. Миссия 01 играбельна; миссия 02 открывается после прохождения миссии 01; миссии 03-06 показаны как закрытые placeholders для будущего учебного пути.

В briefing каждого уровня есть ссылка **Read more** на релевантную страницу документации Arc.

Briefing уровня теперь также объясняет scoring-механику перед стартом.

Текущий polish-pass добавляет подсвеченные кликабельные узлы, tooltip маршрута рядом с точкой назначения, чистую стилизацию линий, след платежного пакета и более понятную mission-плашку над игровым полем.

Визуальная полировка теперь включает CSS-only входные анимации, мягкий свет в hero, каскадное появление карточек миссий и поддержку reduced-motion.

В hero также добавлен тонкий animated protocol-line overlay в духе официального сайта Arc: медленные дуги, вертикальная rail-линия и слабые data streaks за контентом.

Экран уровня отполирован: более чистая simulation surface, Arc-like navy gradients, более читаемая HUD-иерархия и status-сообщения без перекрытия игрового поля.

Миссия 02, **Finality Rush**, теперь доступна после Mission 01. Она объясняет deterministic settlement через expiring payments, ограниченную capacity у settlement lanes и fee budget. Игрок выбирает invoice, отправляет его через settlement lane и должен финализировать минимум четыре платежа до того, как истекут два invoice, оставаясь внутри бюджета $0.09. USDC-пакет теперь летит по маршруту invoice -> lane -> final settlement, чтобы подчеркнуть: sent не равно final.

Код начал разделяться по уровням. Миссия 02 живет в `src/levels/finality-rush.js`, а `src/main.js` теперь только передает reset/update/draw/input активной миссии.

Onchain-слой: после прохождения миссии игрок может ввести nickname и заминтить ERC-721 achievement NFT в Arc Testnet. Контракт генерирует onchain SVG-картинку с логотипом Arc, ArcQuest, названием уровня, score и nickname.

Mint-flow отполирован: в UI теперь везде используется **Mint Badge**, перед минтом показывается live preview бейджа, ссылка на ArcScan отображается короткой кликабельной ссылкой, после успешного минта кнопка блокируется как **Minted** в рамках текущего прохождения, а на mint-экране появляется действие **Next level**, если следующий реализованный уровень доступен.

**My Badges** теперь доступен с главного экрана и с экрана уровня. Подключенный кошелек может загрузить свои ArcQuest ERC-721 бейджи из mint-логов Arc Testnet, декодировать tokenURI каждого бейджа и показать в игре onchain-картинку, уровень, score и nickname. Если Arc RPC отклоняет широкий запрос логов, приложение переключается на fallback: напрямую сканирует владельцев tokenId в контракте.

Replayability-pass: после каждого доставленного платежа граф пересобирается. Узлы меняют позиции, маршруты меняются, комиссии и скорости генерируются заново, а в некоторых волнах появляется нейтрально выглядящий **Fake Claim** route, который показывает красное предупреждение в tooltip и приводит к проигрышу при выборе.

Скоринг начинается с нуля и учитывает скорость плюс эффективность по комиссиям. Каждый доставленный платеж начисляет несгораемую награду до 100 очков; медленная доставка и высокая комиссия уменьшают награду именно за этот платеж, но минимум остается 1 очко.

Багфиксы: детали маршрута теперь живут в hover-tooltip вместо постоянных подписей на линиях, чтобы избежать наложения текста, а при истечении времени показывается проигрыш с одной красной кнопкой **Try again**.

## Как открыть

В этом первом блоке игру можно открыть напрямую в браузере:

```text
C:\Users\user\Documents\ARC\index.html
```

Первая версия специально использует обычный браузерный JavaScript, поэтому при открытии файла напрямую должна появиться игровая карта без установки зависимостей.

Если в терминале доступен Node.js, можно также запустить:

```bash
npm run start
```

Затем открыть:

```text
http://localhost:4173
```
