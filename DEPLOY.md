# Deploy ArcQuest

This guide deploys the ArcQuest achievement NFT contract to Arc Testnet and publishes the static game site.

## 1. Add Arc Testnet to your wallet

Use these official Arc Testnet parameters:

```text
Network name: Arc Testnet
RPC URL: https://rpc.testnet.arc.network
Chain ID: 5042002
Currency symbol: USDC
Explorer: https://testnet.arcscan.app
Faucet: https://faucet.circle.com
```

Get testnet USDC from the faucet before deploying or minting.

## 2. Deploy the NFT contract with Remix

1. Open https://remix.ethereum.org.
2. Create `contracts/ArcQuestAchievements.sol`.
3. Paste the contents of `contracts/ArcQuestAchievements.sol` from this project.
4. Open **Solidity Compiler**.
5. Use compiler `0.8.24` or a newer `0.8.x` compiler.
6. Compile `ArcQuestAchievements.sol`.
7. Open **Deploy & Run Transactions**.
8. Set environment to **Injected Provider - MetaMask**.
9. Confirm MetaMask is connected to **Arc Testnet**.
10. Deploy `ArcQuestAchievements`.
11. Copy the deployed contract address.

## 3. Connect the frontend to the contract

Open `src/main.js` and replace:

```js
const ACHIEVEMENT_CONTRACT_ADDRESS = "0x0000000000000000000000000000000000000000";
```

with your deployed contract address.

## 4. Test minting locally

Wallet injection usually works best from `http://localhost`, not `file://`.

If Node.js is installed:

```bash
npm run start
```

Then open:

```text
http://localhost:4173
```

Flow:

1. Open Mission 01.
2. Complete the level.
3. Click **Mint NFT**.
4. Enter a nickname.
5. Confirm the Arc Testnet transaction.
6. Open the transaction on ArcScan.

## 5. Deploy the static site

ArcQuest is a static site. Use any static host:

- **Vercel:** import the GitHub repo with framework preset **Other**. Use no build command and output directory `.`. The included `vercel.json` sets this explicitly and rewrites page requests to `index.html`.
- **Netlify:** deploy from GitHub or drag the project folder, publish directory `/`.
- **GitHub Pages:** push the repo, then enable Pages from the `main` branch root.

Before deploying, make sure `ACHIEVEMENT_CONTRACT_ADDRESS` is set to your Arc Testnet contract.

If Vercel shows only `Not found`, check two settings:

1. **Root Directory** must be the folder that contains `index.html`.
2. **Output Directory** must be `.`.

## Notes

- The first version uses client-side scoring. This is fine for testnet and demos, but not anti-cheat secure.
- Each wallet can mint one NFT per level.
- Nicknames must be 2-24 characters and can use letters, numbers, `.`, `_`, or `-`.
- The NFT image is generated by the contract as an onchain SVG.
